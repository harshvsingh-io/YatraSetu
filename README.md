## 🌟 Executive Summary

Over **300 million domestic tourists** travel across India each year, concentrating into fragile ecological hotspots (Manali, Shimla, North Goa, Nainital) and causing traffic paralysis, hyper-inflated commercialization, and tons of unmanaged plastic litter. Meanwhile, pristine secondary cultural destinations struggle with economic desertion.

**YatraSetu** solves this crisis by pairing **AI-driven tourism decongestion** with an **incentivized civic restoration layer**:
1. **AI Decongestion Engine**: Reroutes travelers away from choked hotspots into pristine, low-density hidden gems (*Tirthan Valley, Chopta, Gokarna, Orchha, Hampi, Munnar*).
2. **Regenerative Seva Passport**: Links hotel bookings directly with nearby geotagged ecological restoration drives (beach cleanups, alpine trail sweeps, mangrove plantation).
3. **15-Second Anti-Fraud Check-In**: Eliminates proxy volunteering via time-rotating dynamic QR tokens tied to physical GPS boundaries.
4. **Verifiable Government Credentials**: Issues tamper-proof, cryptographic certificates adhering to **NSS / NCC / Ministry of Youth Affairs** standards, authenticated in real time.
5. **Cultural Dialect & Eco-Etiquette Guide**: Equips travelers with authentic indigenous pronunciations and elder taboos (Devta council rules, sacred grove preservation) across 6 Indian linguistic belts.

## ⚡ Key Highlights & Core Capabilities

### 1. 🎨 Bespoke Brandmark & Floating Island Navigation
- Handcrafted geometric SVG emblem combining **twin Himalayan peaks** (*Yatra*), **rising golden sun**, and **suspension bridge** (*Setu*).
- Floating glassmorphism pill navigation with backdrop blur, active link indicators, and 1-click **Judge Demo Access**.

### 2. 🏔️ Interactive Hero Journey Showcase (`HeroJourneyShowcase.tsx`)
- Multi-tab showcase across prominent Indian micro-destinations (*Tirthan Alpine, Gokarna Coast, Chopta Meadows*).
- Displays real-time **Crowd Pressure Indexes**, ambient weather, verified eco-homestays, and directly linked **community restoration drives** with attendee rosters and RSVP actions.

### 3. 🔍 Zero-Latency City Autocomplete & Dynamic Discovery (`/discover`)
- Pre-indexed database of **40+ premier Indian destinations** with sub-5ms instant autocomplete and graceful Nominatim geocoding fallback.
- **Dynamic City-Specific Hydration**: Selecting any city (e.g. *Manali, Kasol, Chopta, Hampi, Orchha, Udaipur, Varanasi*) instantly populates:
  - Vetted eco-homestays, wooden cabins, and heritage havelis.
  - Authentic cultural & nature attractions.
  - Live localized conservation drives.
  - Interactive **Stay Map** toggle with geocoded pins.
  - Regional dialect phrases and sacred eco-taboos.

### 4. 📜 Verifiable Seva Registry & Official Diplomas (`/certificates`)
- Official parchment diploma viewer with national seal watermarking, digital signatory stamps, and high-contrast verification QR codes.
- **Cryptographic Hash Authenticator**: Hackathon judges and universities can verify credentials on-demand (`/certificates?hash=YATRA-NSS-2026-8841`).
- One-click **PDF Export** and **Shareable Registry Link** generator.

### 5. 🗣️ Indigenous Dialect & Eco-Etiquette Guide (`/phrasebook`)
- Audio pronunciations powered by browser speech synthesis across **6 linguistic zones**:
  - **Pahadi & Kullvi** (*Himachal Pradesh*)
  - **Garhwali & Kumaoni** (*Uttarakhand*)
  - **Konkani** (*Goa & Coastal Karnataka*)
  - **Malayalam** (*Kerala*)
  - **Bhoti / Ladakhi** (*Ladakh*)
  - **Marwari** (*Rajasthan*)
- Curated indigenous eco-taboos (e.g. *Never touching Devta stones in Shangarh*, *No chemical soaps in Bhagirathi springheads*).

### 6. 🤖 Live Gemini AI Travel Concierge (`/api/ai-concierge`)
- Interactive conversational AI assistant generating sustainable, budget-tailored, decongested itineraries with zero paid API overhead.

### 7. 📲 Offline Seva Pass & Anti-Fraud Dynamic QR (`/offline-pass`)
- Designed for zero-connectivity remote Himalayan bugyals and river valleys.
- Generates 15-second rotating cryptographically signed offline tokens for volunteer verification.

### 8. 📸 Geo-Tagged Civic Litter Bounties (`/report-litter`)
- Allows travelers to document dumped plastic or polluted waterbodies with geotags and severity classification, triggering cleanup bounties and notifying local volunteer groups.

### 9. 🏛️ Interactive Heritage AR Site Explorer (`/heritage`)
- 3D spatial models and conservation histories of UNESCO World Heritage Monuments (*Hampi Stone Chariot, Konark Wheel, Ajanta Caves*).

## 🚀 Getting Started Locally

### 1. Prerequisites
- **Node.js**: v18.17.0 or higher
- **npm**: v9.0.0 or higher

### 2. Clone the Repository
```bash
git clone https://github.com/harshvsingh-io/YatraSetu.git
cd YatraSetu
npm install
```

### 3. Environment Variables (Optional)
The application works **completely out of the box** with seeded mock and live OpenStreetMap data. If integrating real Supabase or Gemini keys:

```bash
cp .env.local.example .env.local
```

```env
# Supabase (Optional — mock demo auth functions automatically without keys)
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key

# Gemini AI (Optional — fallback AI engine included)
GEMINI_API_KEY=your-gemini-api-key
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 5. Production Build
```bash
npm run build
npm run start
```
